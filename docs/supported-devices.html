Supported Devices

MiNator works on any Xiaomi / Redmi / POCO device running MIUI or HyperOS with ADB access. The table below lists confirmed tested devices.

ℹ Note

Tested your device? Open an issue on GitHub ↗ with your results and we'll add it here.

Device OS Version Status
Xiaomi 14 HyperOS 3.0 ✓ Working
Xiaomi Redmi 14C HyperOS 2.0 ✓ Working — runs very smoothly
Xiaomi Redmi Pad 2 HyperOS 2.0 ✓ Working

More devices coming as tested. MiNator is designed to work on all MIUI and HyperOS devices — most packages are consistent across the lineup.

Поддържани устройства

MiNator работи на всяко Xiaomi / Redmi / POCO устройство с MIUI или HyperOS и ADB достъп. Таблицата по-долу съдържа потвърдено тествани устройства.

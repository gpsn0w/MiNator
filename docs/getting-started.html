Getting Started

⚠ Important

MiNator removes apps using pm uninstall -k --user 0. This does NOT permanently delete anything — it only disables apps for your user. A factory reset restores them. No root is required.

Quick Start Checklist

Before you begin, make sure you have:

  • ✓ A Xiaomi or Redmi device running MIUI or HyperOS
  • ✓ ADB installed on your computer
  • ✓ USB cable or Wireless ADB set up
  • ✓ USB Debugging enabled on your phone

Step 1 — Enable Developer Options

1

Open About Phone

Go to Settings → About phone.
Find MIUI Version or HyperOS Version and tap it 7 times.
You'll see: "You are now a developer!"

2

Enable USB Debugging

Go to Settings → Additional settings → Developer options.
Enable USB debugging.

3

Connect your phone

Connect your phone via USB cable.
When prompted on the phone, tap Allow.

Step 2 — Install ADB

Mac
brew install android-platform-tools
Ubuntu / Debian
sudo apt install adb
Fedora
sudo dnf install android-tools

Windows: Download Platform Tools ↗ — extract and add to PATH.

Step 3 — Run MiNator

The easiest way — one command, nothing saved to disk:

Mac / Linux
bash <(curl -fsSL https://raw.githubusercontent.com/gpsn0w/MiNator/main/install.sh)
Windows (PowerShell)
irm https://raw.githubusercontent.com/gpsn0w/MiNator/main/install.ps1 | iex

Or download the files manually from the latest release ↗.

Wireless ADB (Android 11+)

No USB cable needed:

1

Go to Developer options → Wireless debugging → Enable.
Tap Pair device with pairing code.

2
Pair
adb pair IP:PORT
3
Connect
adb connect IP:PORT
✓ Done

After MiNator finishes, restart your phone to apply all changes.

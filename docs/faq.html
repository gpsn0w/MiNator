FAQ

Is root required?

No. MiNator uses pm uninstall -k --user 0 via ADB, which works on any unlocked device without root.

Will this brick my phone?

No. The -k flag keeps the APK on the device — it's only disabled for your user. A factory reset restores everything. MiNator never removes system-critical packages.

Can I restore a removed app?

Yes, with ADB:

adb shell cmd package install-existing com.package.name

Or simply do a factory reset to restore all apps.

Nothing gets saved to my computer?

Correct. When you use the one-liner commands, the scripts run entirely in memory and nothing is written to disk. After MiNator finishes, there are no leftover files.

Will Find My Device stop working?

Only if you remove Mi Cloud Backup (com.miui.cloudbackup), and even then it depends on your setup. MiNator warns you twice before removing it, and intentionally leaves com.miui.cloudservice intact since it's required for Find My Device.

Does it work on HyperOS?

Yes. MiNator supports both MIUI and HyperOS. It was tested on Xiaomi 14 — HyperOS 3.0.

What if a package is not found?

MiNator automatically tries alternative package names (e.g. com.xiaomi.mipicks → com.miui.mipicks). If neither is found, it reports the app as already removed or not present on your device.

Does it support multiple devices?

Yes. If multiple devices are connected, MiNator uses the first authorized one. Use adb devices to see what's connected.

I see "Device found but NOT authorized"

Unlock your phone screen and tap Allow on the USB Debugging dialog, then run MiNator again.

Is the source code available?

The source code is on GitHub ↗. You can read every line before running anything.

FAQ

Нужен ли е root?

Не. MiNator използва pm uninstall -k --user 0 през ADB, което работи на всяко отключено устройство без root.

Ще убие ли телефона ми?

Не. Флагът -k запазва APK-то на устройството — само го деактивира за твоя потребител. Фабричният ресет връща всичко. MiNator никога не маха системно-критични пакети.

Мога ли да върна махнато приложение?

Да, с ADB:

adb shell cmd package install-existing com.package.name

Или просто направи фабричен ресет за да върнеш всички приложения.

Нищо не се записва на компютъра ми?

Точно така. Когато ползваш едноредовите команди, скриптовете се изпълняват изцяло в паметта и нищо не се записва на диска. След като MiNator приключи, не остават файлове.

Ще спре ли Find My Device да работи?

Само ако махнеш Mi Cloud Backup (com.miui.cloudbackup), и дори тогава зависи от настройките ти. MiNator те предупреждава два пъти преди да го маха, и умишлено оставя com.miui.cloudservice непокътнат.

Работи ли на HyperOS?

Да. MiNator поддържа и MIUI, и HyperOS. Тестван на Xiaomi 14 — HyperOS 3.0.

Какво ако пакетът не е намерен?

MiNator автоматично опитва алтернативни имена на пакети (напр. com.xiaomi.mipicks → com.miui.mipicks). Ако нито едното е намерено, съобщава, че приложението е вече махнато или не е на устройството.

Поддържа ли множество устройства?

Да. Ако са свързани няколко устройства, MiNator ползва първото оторизирано. Използвай adb devices за да видиш кое е свързано.

Виждам "Device found but NOT authorized"

Отключи екрана на телефона и натисни Разреши на диалога за USB Debugging, след което стартирай MiNator отново.

Изходният код достъпен ли е?

Изходният код е в GitHub ↗. Можеш да прочетеш всеки ред преди да пускаш каквото и да е.

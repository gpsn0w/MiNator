FAQ

Is root required?

No. MiNator uses pm uninstall -k --user 0 via ADB, which works on any unlocked device without root.

Will this brick my phone?

No. The -k flag keeps the APK on the device — it's only disabled for your user. A factory reset restores everything. MiNator never removes system-critical packages.

Can I restore a removed app?

Yes, with ADB:

adb shell cmd package install-existing com.package.name

Or simply do a factory reset to restore all apps.

Nothing gets saved to my computer?

Correct. When you use the one-liner commands, the scripts run entirely in memory and nothing is written to disk. After MiNator finishes, there are no leftover files.

Will Find My Device stop working?

Only if you remove Mi Cloud Backup (com.miui.cloudbackup), and even then it depends on your setup. MiNator warns you twice before removing it, and intentionally leaves com.miui.cloudservice intact since it's required for Find My Device.

Does it work on HyperOS?

Yes. MiNator supports both MIUI and HyperOS. It was tested on Xiaomi 14 — HyperOS 3.0.

What if a package is not found?

MiNator automatically tries alternative package names (e.g. com.xiaomi.mipicks → com.miui.mipicks). If neither is found, it reports the app as already removed or not present on your device.

Does it support multiple devices?

Yes. If multiple devices are connected, MiNator uses the first authorized one. Use adb devices to see what's connected.

I see "Device found but NOT authorized"

Unlock your phone screen and tap Allow on the USB Debugging dialog, then run MiNator again.

Is the source code available?

Yes — fully open source on GitHub ↗. You can read every line before running anything.
